My goal with this project is to help me learn python through a focused goal. 
I identified a weakness in the bakeries stock management system and presented the problem to the manager who loved the idea. After further discussion we decided on an efficiency application that can do mundane tasks and manage various aspects of the bakery digitially.
The initial goal is to create a stock system that takes recipes and production inputs and calculates stock used and total stock left to know what needs to be ordered instead of doing manual checks. Delivery invoices can then be inputted and this will update the total stock.
Future additions include features such as: recipe input and look-up, wastage, costings and audit logging.
